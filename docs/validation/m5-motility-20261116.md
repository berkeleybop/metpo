# Motility parent definition candidate

Issue [#661](https://github.com/berkeleybop/metpo/issues/661) concerns the
inherited meaning of METPO:1000703. Its parent, METPO:1000701, currently defines
positive autonomous movement, although the parent groups both motile and
nonmotile phenotypes. This candidate defines the parent as a phenotype describing
whether and how an organism moves independently under its own power.

The maintained source is `src/templates/metpo_sheet.tsv`, based on main commit
`62e388af7ea004b2e1fd0cd2b05db0174dcaea2e`. The identifier, label, direct parent,
source annotation OMP:0000001, synonyms, mappings and all child rows are retained.
The motile and nonmotile classes remain siblings; locomotion mechanisms remain
under the positive branch. The existing OMP source describes a general motility
phenotype and has distinct presence and absence children. Its public source
navigation is [OMP presence](https://microbialphenotypes.org/wiki/index.php/Category:OMP:0000005_!_presence_of_cell_motility)
and [OMP absence](https://microbialphenotypes.org/wiki/index.php?title=Category%3AOMP%3A0000133_%21_absence_of_motility).
The retained local OMP OWL was also inspected. No publication passage is quoted.

This is a definition repair. Text definitions are annotation assertions, so an
OWL reasoner alone cannot detect or validate the natural-language conflict.
Tests therefore inspect the negative child's inherited axis and verify the
regenerated parent, positive child, negative child and three mechanism classes.
No historical release, source organism record or scientific verdict is changed.

## Reproduce the candidate

Use ROBOT 1.9.8 and the source from this branch:

```sh
robot template \
  --add-prefix 'METPO: https://w3id.org/metpo/' \
  --add-prefix 'qudt: http://qudt.org/schema/qudt/' \
  --add-prefix 'oboInOwl: http://www.geneontology.org/formats/oboInOwl#' \
  --template src/templates/stubs.tsv \
  --template src/templates/metpo_sheet.tsv \
  --template src/templates/metpo-properties.tsv \
  --template src/templates/deprecated.tsv \
  annotate --ontology-iri https://w3id.org/metpo/components/metpo_sheet.owl \
  convert --format owl --output .temp/m5-motility-20261116/candidate.owl
python scripts/adhoc/check_motility_candidate_20261116.py \
  .temp/m5-motility-20261116/candidate.owl
```

The branch deliberately carries the maintained source and a checked candidate
receipt, without publishing a new release artifact. The Google Sheet lifecycle
remains tracked separately in METPO #602; this candidate uses existing tracked
templates and never refreshes them from the Sheet.

Independent read-only review by the separate local-authorities agent accepted
the candidate after checking the one-cell source diff, three focused tests and
the persisted candidate hash/semantic check. No material finding remained.
